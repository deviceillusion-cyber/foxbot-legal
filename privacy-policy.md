# Fox Bot - Privacy Policy

Fox Bot collects only the data required to operate its moderation, utility, and ticket features.

## Data We Collect
- User IDs
- Message IDs (only when needed for moderation)
- Ticket information
- Server configuration settings

Fox Bot does NOT collect:
- Direct messages
- Personal information
- Payment information

## Data Storage
Data is stored temporarily in memory or in the bot’s database for functionality.  
Data is not shared, sold, or used for advertising.

## User Rights
Users may request deletion of stored data by contacting the bot owner.

## Contact
For questions, contact the bot owner on Discord
